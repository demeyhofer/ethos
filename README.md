# ETHOS — A Cidade das Escolhas

Jogo narrativo sobre ética, decisões e consequências, criado para o Módulo 4 (Tecnologia em sala de aula) do MBA em Educação.

Cada aula é uma ilha, e cada ilha segue o ciclo **CDP** (Conectar → Desenvolver → Praticar). A prática é baseada na Zona de Desenvolvimento Proximal de Vygotsky:

- **Missão solo:** mostra o nível de desenvolvimento real.
- **Cofre em dupla:** cada pessoa tem metade das pistas e a dupla precisa conversar para abrir o cofre (nível de desenvolvimento potencial).
